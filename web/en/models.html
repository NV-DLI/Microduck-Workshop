Models and data

Every main-path lab uses explicitly named fixed files. Download once and reuse them across chapters.

Quick reference · No retraining required

These files are included in Git without Git LFS or a separate model account. models/manifest.json records sizes, sources, and SHA-256 identities. Model identity checks guard against accidental same-name replacements.

Practice data and your outputs

datasets/sample/ is a small image-and-label practice set for detector inference and short training. It is not enough to establish real-world generalization. Student checkpoints and logs belong in outputs/; do not copy them over the course files in models/.

Sources and usage terms

Robot geometry, community policies, and dependencies retain their source terms. The course-code license does not override third-party asset licenses. Before redistributing changes, read the repository’s attribution and license notices.
