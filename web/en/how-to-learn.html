SELF-PACED WORKSHOP

How to take this course

Choose observation, fixed-model labs, or training practice. All three follow the same learning sequence.

About 5 minutes · No GPU required

Choose a learning path

PathWhat you doWhat you need
ObserveRead, inspect the 3D assembly, watch demonstrations, and answer checks.A modern browser
Use fixed models (recommended)Copy terminal commands, run simulation, and record observations.A prepared GPU environment
Practice trainingAdd your own training, export, and evaluation.Additional runtime and disk space

For a first pass, complete the fixed-model path, then return to Chapters 3, 4 and 7 for training. Without a GPU, follow the reading path in order. The interactive model and examples do not launch Isaac.

Prerequisites

  • Open a Linux terminal, change directories, and copy multiline commands.
  • Read basic Python functions, arrays, and parameters. Prior PPO knowledge is not required.
  • Understand positions, angles, and velocities; robot coordinate frames are introduced in the course.
About your training results

Your checkpoint is a practice artifact. Later chapters explicitly use the course models in models/; they never select the latest training run automatically. Using your own policy requires an explicit checkpoint and a new evaluation.

A useful lab routine

  • Read the expected result before running a command.
  • Run commands from the repository root. Use a new output directory for every run.
  • Keep the command, seed, and result—including failures.
  • Answer the chapter check before moving on.

Reading and exercise durations are planning estimates, not training-time guarantees. The first launch may download assets, compile kernels, and populate rendering caches.
