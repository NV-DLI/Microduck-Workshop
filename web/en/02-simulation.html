SELF-PACED WORKSHOP

Run your first simulation

Connect observations, actions, and physics using the fixed walking model.

Chapter 2 · About 30 minutes · GPU

Before the lab

Complete setup and model verification. Open a desktop terminal on the GPU machine and enter Microduck-Workshop. This chapter loads an existing model and focuses on a run’s inputs, outputs, and visible behavior.

What the policy receives and produces

This chapter runs inference with a trained policy. It maps the current observation to 14 joint actions without updating neural-network parameters. Changing the velocity command tests the same model under a different request; it is not training. Choosing a different model file changes the policy.

Observation, in interface orderWidthWhat it tells the policy
Angular velocity and projected gravity6Body rotation and tilt
Relative joint positions14Pose relative to the nominal posture
Joint velocities14Motion at each joint
Previous action14Previous control output and temporal context
Velocity, head, and body commands3 + 4 + 6Requested behavior

These values total 61. Reordering joints breaks their meaning even if the input still has 61 entries: the policy might read a knee as a hip. Course entry points preserve ordering, nominal posture, and control timing. Begin by changing commands, duration, and output directories; modify observation construction only after understanding the interface.

Load the fixed walking policy

Terminal · Bash
python3 scripts/workshop.py walk \
  --model models/walk.onnx \
  --velocity 0.30 0.00 0.00 \
  --seconds 12 \
  --seed 42 \
  --output outputs/walk-forward-01
ArgumentMeaning
--modelExplicit ONNX policy file
--velocityForward, lateral, and turn policy commands—not measured velocity
--secondsSimulation duration
--seedRandom seed
--outputA new directory for this run

Expected result: a separate simulation window opens with the fixed policy controlling the robot. Watch alternating support, persistent body rotation, and drift around stopping. Use a new output directory for each observation.

Compare two commands

Terminal · Bash
python3 scripts/workshop.py walk \
  --model models/walk.onnx \
  --velocity 0.00 0.00 0.00 \
  --seconds 12 \
  --seed 42 \
  --output outputs/walk-hold-01

Keep the model, duration, and seed unchanged, and set the command to zero. A zero command requests standing, but does not guarantee a perfectly motionless body. Small commands may not produce proportionally small motion; learned responses must be observed.

Check your understanding

Does changing the forward command from 0.30 to 0.15 guarantee exactly half the walking speed?

Show explanation

No. A command is an input; achieved speed is an outcome. Measure displacement and time under comparable conditions, including falls, unwanted turning, and command dead zones.

Read the outputs of one run

Physics advances every 0.005 seconds. The policy produces an action every 0.02 seconds, so four physics steps occur before the next policy update. Display refresh, physics frequency, and policy frequency are different quantities: a slow window does not automatically change simulated time.

The lab holds a zero velocity command for two seconds, then applies your command. After the run, report.json records elapsed simulation time, model identity, and whether a fall occurred. trajectory.json records positions and measured velocities over time. A fall ends the run instead of silently resetting it. This nominal single-robot observation does not replace the full perception-and-recovery task in Chapter 7.

Compare fell first, then displacement and measured velocity. Command entries are forward body velocity, lateral body velocity, and yaw rate. Units are meters, meters per second, and radians per second. Keep the seed fixed and change one parameter at a time so you can interpret the difference.

Check your understanding

The command is 0.30 m/s and measured speed averages 0.20 m/s without a fall. Is velocity tracking perfect?

Show explanation

No. Survival describes stability; velocity error describes tracking. Record them separately.
