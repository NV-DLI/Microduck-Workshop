SELF-PACED WORKSHOP

Organize tasks and accumulate skills with ASPIRE

Once reliable skills exist, how can execution feedback improve task programs and retain reusable experience?

Chapter 8 · Estimated learning time: 25 minutes

A capable agent needs reliable actions

The VLA addresses actions from current observations. Longer tasks add decisions: find the ball or inspect the goal first, recover after a miss, or move to another target after scoring. A robot agent can organize such decisions by connecting language goals to executable skills.

ASPIRE: try, diagnose, improve and reuse

ASPIRE is NVIDIA’s open robot-skill discovery framework. An agent writes and revises control programs, inspects execution traces, diagnoses failure and tests repairs. Validated experience becomes reusable skills for later tasks. This improves programs and skill knowledge, unlike GR00T training that updates neural parameters.

For Microduck, first validate observation, short movements, controlled stopping and outcome checks on the same simple field, then compose a complete shot. Balancing continues while the agent reasons or waits for network responses. New environments and longer tasks build on those reliable capabilities.

Combining GR00T with ASPIRE

LayerQuestionFootball example
ASPIRE / task agentWhat to invoke, check and improveChoose to reposition after observing an offset ball
GR00T / action policyWhich actions fit this observationGenerate approach or contact actions
Local controlHow to execute promptly and stablyBalance, limits, braking and timeouts

This hierarchy allows gradual replacement of capabilities without giving a large model every joint at once. Coordinates, timing and units still matter; clear tool interfaces encapsulate those details so the agent can compose them.

Further reading: Agnes Harness

Agnes Harness also organizes robot tasks around models, tools and feedback. Its device integration and plugin design are useful further reading. Compare how tools connect to robots, how results return and how failures inform reuse. ASPIRE supplies this chapter’s main skill-discovery methodology.
