在容器内运行下面的命令，核对固定模型的文件大小与哈希。

Terminal · 容器内#
python3 scripts/run.py verify-models

这些文件随 Git 仓库一同提供，克隆仓库即可使用，无需 Git LFS 或额外的模型账户。models/manifest.json 记录了文件大小、来源和 SHA-256；实验入口在运行前会核对模型身份，避免误用同名文件。当前默认检测器的相对路径与 SHA-256 记录在 models/scene-detector/deployment.json。

仓库自带。 第 2–3 部分实验和板载策略（Onboard）所用的权重；3.2 节预先训练好的 PPO 行走结果与坡地训练日志在 datasets/walking-ppo 和 datasets/terrain-ppo（容器内 /workspace/Microduck-Workshop/datasets/，只读）。datasets/terrain-rollers-ppo-experiment 是一次没有学会上坡的轮滑坡地训练记录，作为奖励设计的反例保留，不是可用的坡地模型。

单独的资料包。 5.3 节的 GR00T 步行射门数据、特征缓存与训练好的检查点来自单独的 GR00T 课程资料包（容器内 course-data/groot-walking，用 python3 scripts/groot_walking.py verify 核对）。GR00T 基础模型与 Cosmos-Reason2-2B 处理器按其授权与访问条件从 Hugging Face 下载。

练习数据与自己的输出#

datasets/scene-sample/ 是一套小型图像与标签样例，本课的动手实验不直接使用；它的规模不足以检验模型在真实环境中的泛化能力。自行训练的模型和日志请保存在 outputs/，models/ 中的课程文件保持原样。

来源与使用条款#

机器人几何、社区策略和依赖组件分别适用各自的来源与许可条款；第三方资产以其自身条款为准，课程代码的许可不能替代这些条款。分发修改版本前，请先查阅仓库中的 来源与许可说明。
