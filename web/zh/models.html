这些文件随 Git 仓库一同提供，不需要 Git LFS 或额外的模型账户。models/manifest.json 记录了文件大小、来源和 SHA-256；实验入口在运行前会核对模型身份，避免误用同名文件。 新检测器的相对路径与 SHA-256 单独记录在 models/indoor-detector/deployment.json，原七份文件保持不变。

练习数据与自己的输出

datasets/sample/ 是一套小型图像与标签练习集，用于体验检测推理和短训练流程，但不足以证明模型能够泛化到真实环境。自行训练的模型和日志应保存在 outputs/，不要将其复制到 models/ 并覆盖课程文件。

来源与使用条款

机器人几何、社区策略和依赖组件分别保留各自的来源与许可条款，课程代码的许可并不覆盖第三方资产。分发修改版本前，请先查阅仓库中的 来源与许可说明。
