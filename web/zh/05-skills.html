3.5 （拓展）社区技能：奖励设计#

上一节用转向跟踪奖励约束坡地行走。这一节再看两个社区例子：怎样奖励重心转移，怎样奖励双脚贴住球面。重点是把动作要求写成可计算的公式。

第 3.5 节 · 阅读与分析 · 预计学习时长 20 分钟

两个奖励设计例子#

以下公式和代码来自社区公开的固定版本，只用于阅读；课程命令不会加载这些模型。视频是作者的仿真演示，用来帮助理解任务。

单脚站立：把质心目标移到支撑脚#

要抬起一只脚，先把重心移到另一只脚上。可以让目标位置从两脚中点逐渐移向支撑脚，再奖励实际质心接近这个目标。混合进度 \(\htmlData{sym=alpha_f}{\alpha}\) 从 0 走向 1 时，目标随之移动；放下脚时反向变化。

质心目标随混合进度移动（权重 3）
\[\htmlData{sym=p_target}{p^{*}_{xy}}=(1-\htmlData{sym=alpha_f}{\alpha})\,\htmlData{sym=p_mid}{p_{\mathrm{mid}}}+\htmlData{sym=alpha_f}{\alpha}\,\htmlData{sym=p_stance}{p_{\mathrm{stance}}},\qquad \htmlData{sym=r_com}{r_{\mathrm{com}}}=\htmlData{sym=exp}{\exp}\!\left(-\frac{\|\htmlData{sym=c_com}{c_{xy}}-\htmlData{sym=p_target}{p^{*}_{xy}}\|^2}{\htmlData{sym=sigma_c}{\sigma_c}^2}\right)\]
变量含义
\(p^{*}_{xy}\)
质心的目标水平位置（m）：从两脚中点逐渐移到支撑脚上方。
\(\alpha\)
姿势混合进度：0 为双脚站立，1 为单脚站立。
\(p_{\mathrm{mid}}\)
两只脚的中点（水平位置，m）。
\(p_{\mathrm{stance}}\)
支撑脚的水平位置（m）。
\(r_{\mathrm{com}}\)
质心目标项（权重 3）。
\(\exp\)
指数函数：把平方误差变成 0 到 1 之间的平滑奖励。
\(c_{xy}\)
整机质心的水平位置（m），由仿真对全身所有部件计算。
\(\sigma_c\)
质心误差尺度（m）：越小，奖励越严格。

误差越小，\(\htmlData{sym=r_com}{r_{\mathrm{com}}}\) 越接近 1。\(\htmlData{sym=sigma_c}{\sigma_c}\) 决定允许多大的偏差；奖励使用整机质心，包含头、躯干和四肢的质量。

Python · 奖励核心节选完整代码 ↗

1移动目标，再计算误差

stance 选择支撑脚，mid 是两脚中点；alpha 决定二者的混合比例。最后把质心的水平误差转换为指数奖励。

1
stance = torch.where((side > 0).unsqueeze(1), right, left)
mid = 0.5 * (left + right)
a = alpha.unsqueeze(1)
target_xy = (1.0 - a) * mid[:, :2] + a * stance[:, :2]
com_xy = _robot_com_xy(env, asset)
dist2 = ((com_xy - target_xy) ** 2).sum(dim=-1)
return torch.exp(-dist2 / (std ** 2))

完整奖励还会约束支撑脚接触、抬脚高度和身体姿态。这里选出的质心项说明了一种写法：让奖励的目标随动作进度变化，而不是始终奖励同一个站姿。其余项见完整配置。

篮球平衡：让身体和双脚贴合球的位置#

站到球上后，机器人需要让身体留在球顶附近、双脚贴住球面。下面两项分别约束机身的水平位置和脚底到球心的距离。球心和脚底位置从仿真状态读取，用于计算奖励。

球上站姿：对准球心与双脚贴球（权重 2、1）
\[\htmlData{sym=r_center}{r_{\mathrm{center}}}=\htmlData{sym=exp}{\exp}\!\left(-\frac{\|\htmlData{sym=p_ball}{p_{\mathrm{ball}}}-\htmlData{sym=p_root}{p_{\mathrm{root}}}\|_{xy}^2}{0.04^2}\right),\qquad \htmlData{sym=r_feet}{r_{\mathrm{feet}}}=\frac{1}{2}\sum_{\mathrm{L,R}}\htmlData{sym=exp}{\exp}\!\left[-\left(\frac{\|\htmlData{sym=p_foot}{p_{\mathrm{foot}}}-\htmlData{sym=p_ball}{p_{\mathrm{ball}}}\|-(\htmlData{sym=R_ball}{R}+0.012)}{0.02}\right)^2\right]\]
变量含义
\(r_{\mathrm{center}}\)
机身对准球心项（权重 2）。
\(\exp\)
指数函数：把平方误差变成 0 到 1 之间的平滑奖励。
\(p_{\mathrm{ball}}\)
篮球球心位置（m），直接从仿真状态读取；部署的策略看不到它。
\(p_{\mathrm{root}}\)
机器人根部（机身）位置（m）。
\(r_{\mathrm{feet}}\)
双脚贴在球面上项（权重 1），两只脚取平均。
\(p_{\mathrm{foot}}\)
某只脚的足底参考点位置（m）。
\(R\)
篮球半径，0.12 m。

第一项把机身拉回球心上方；第二项要求每只脚到球心的距离接近“球半径 + 12 mm 鞋底间隙”，再对两脚取平均。偏差越小，得分越高。

Python · 奖励核心节选完整代码 ↗

1奖励脚底贴住球面

d 是每只脚到理想球面的距离误差；std 为 0.02 m。每只脚分别计算奖励，再取平均。

1
robot = env.scene[asset_cfg.name]
feet = robot.data.site_pos_w[:, asset_cfg.site_ids, :]
d = torch.linalg.norm(feet - _bb_ball_pos(env)[:, None, :], dim=-1) - (ball_radius + sole_gap)
return torch.exp(-(d * d) / (std * std)).mean(dim=-1)

这展示了另一种写法：用任务对象的几何关系定义目标。训练时能读取球的真实位置来计算奖励，并不意味着部署时的策略也能直接获得它。其余奖励项见完整配置。
