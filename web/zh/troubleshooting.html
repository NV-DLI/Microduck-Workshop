Terminal · Bash

记录第一条失败信息，比重复执行完整训练更有帮助。检查命令是否在仓库根目录运行、当前 Python 是否属于锁定环境，以及模型校验是否全部通过。

常见问题

现象检查与处理
窗口没有打开使用 GPU 机器的桌面终端；检查 DISPLAY 与驱动，不要把远程纯命令行会话当作图形桌面。
第一次启动很慢查看日志是否仍在下载资源或编译；等待初始化，不要反复启动多个实例。
提示输出目录已存在为新实验换一个目录名。保留上一场的结果。
显存或内存不足先减少学生训练的环境数或检测 batch；不要同时运行多个仿真。
模型校验失败重新获取仓库中的原模型，确认没有覆盖固定文件。
自己的模型走不好短训练只保证体验流程。比较奖励、回合长度和独立表现；下一章使用固定模型继续。
机器人停止或没有进球查看任务结果与观测有效性。停止可能是信息不足时的正确行为，不能直接算作进球成功。

查看一次运行

Terminal · Bash
python3 scripts/workshop.py report --run outputs/football-01

提交问题时提供命令、随机种子、环境检查结果和第一条报错。不要只提供“成功”或“失败”两个字，也不要发送账户密码或访问令牌。
