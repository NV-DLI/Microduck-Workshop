认识 Microduck：先来踢一场球

先用键盘指挥 Microduck 走路、转向和踢球，再看看 Isaac Sim 如何把场景、机器人和预训练策略连接起来。

第 1 章 · 自学与实践

一只可以学习新技能的小机器人

Microduck 是 Pollen Robotics 与 Hugging Face 推出的开源双足机器人。它有 14 个主动关节，可以通过训练获得行走、踢腿等技能。本课程使用 NVIDIA Isaac Sim 搭建可反复试验的场景，用 Isaac Lab 组织训练与评测，逐步让机器人自己找到足球并完成射门。先不训练：加载官方已经训练好的行走与右脚踢球 ONNX 策略，体验一次手动射门。

打开球场，用键盘试一试

先完成环境准备，在课程仓库根目录打开终端。命令会打开 Isaac Sim，场景中的机器人、足球和球门与第 7 章自主射门任务采用相同的尺寸与物理配置。将输入法切换到英文，鼠标点击仿真窗口后，用下面的按键操作。若按键没有反应，先检查是否仍处于中文输入状态。

Terminal
python3 scripts/workshop.py manual \
  --seconds 600 \
  --output outputs/manual-football-01
按键作用
W / S向前 / 向后走
A / D向左 / 向右侧移
Q / E向左 / 向右转
松开方向键给出零速度指令，回到站立
空格执行一次右脚踢球，然后切回站立
R / Esc重置本次场景 / 退出

先走到球旁边，再停下来：球应位于右脚前方，身体朝向球门。按空格出脚。若踢空，先调整站位；若失去平衡，按 R 重来。这里由您判断球在哪里、应该朝哪走，策略只负责把指令变成关节动作。一次没有进球，也能帮助您发现自主射门系统必须解决什么问题。

Isaac Sim 如何构成这场实验

机器人 USD 不只是一张好看的网格：关节定义连接关系，碰撞形状决定接触位置，质量与惯量影响加速和转身，舵机模型影响目标角度如何变成实际运动。球的半径为 3.5 cm、质量为 45 g；球门内宽为 24 cm。Isaac Sim 提供场景与渲染，课程使用 Isaac Lab 的任务配置接入 Newton 物理后端。

两个不到 1 MB 的策略如何控制全身

文件大小作用
walk.onnx793,705 字节，约 0.79 MB速度非零时行走；速度为零时站立
kick-teacher.onnx793,685 字节，约 0.79 MB右脚踢球动作

两个官方策略都接收 61 维观测，输出 14 个关节动作。网络包含 512、256、128 个单元的三个隐藏层，使用 ELU 激活；输入归一化参数已包含在 ONNX 中，不要再做一次不匹配的归一化。键盘没有逐个操纵关节，而是改变速度指令。出脚时速度归零，短时调用踢球策略，再平滑切回站立。这里不加载课程的踢球残差模型。

Python · 核心代码节选完整代码 ↗
obs = env.observation_manager.compute(update_history=True)['policy']
action = walk(obs)
if kick_start is not None:
    phase = (step - kick_start) * .02
    weight = 1. if phase < .14 else max(0., 1. - (phase - .14) / .12)
    if weight:
        action = torch.lerp(action, kick(obs), weight)
env.action_manager.process_action(action)

手动实验把踢球保持时间设为 0.14 秒，再用 0.12 秒切回站立；这是本实验的技能切换设置，不是对官方权重的重新训练。策略文件大小小于 1 MB，不代表完整仿真只需要这么多显存。
