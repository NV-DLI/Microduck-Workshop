SELF-PACED WORKSHOP

如何学习本课程

选择观看、固定模型实践或训练练习。三种方式共用同一条知识主线。

阅读约 5 分钟 · 无需 GPU

选择学习方式

方式你要做什么需要什么
观看学习阅读解释，操作 3D 模型，播放 GIF，回答检查题。现代浏览器
固定模型实践（推荐）复制命令，在本机终端运行仿真，观察与记录结果。已准备好的 GPU 环境
训练练习在实践基础上自己训练、导出和评估。更多运行时间和磁盘空间

首次学习建议先按固定模型完成主线，再回到第三章和第五章练习训练。没有 GPU 也可以按顺序读完，交互模型和示例不需要启动 Isaac。

你需要知道什么

  • 能够在 Linux 中打开终端、切换目录和复制多行命令。
  • 能读懂简单的 Python 函数、数组和参数。无需先掌握 PPO。
  • 知道坐标、角度和速度的含义；课程会解释机器人坐标系。
关于训练结果

你自己的检查点只用于练习。后续章节默认使用 models/ 中的课程模型，不会自动挑选“最近训练的模型”。如果希望使用自己的策略，需要显式指定检查点，并重新评估。

每次实验怎么做

  • 先读“预期结果”，知道自己应该观察什么。
  • 在课程仓库根目录执行命令。每个输出目录只用于一次运行。
  • 保存命令、随机种子和结果；失败也保留。
  • 回答本章检查题，再进入下一章。

正文给出的阅读与练习时长是学习安排，不是训练耗时保证。首次启动可能需要下载资源、编译内核和建立渲染缓存。
