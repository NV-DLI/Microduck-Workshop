SELF-PACED WORKSHOP

如何学习本课程

选择观看、固定模型实践或训练练习。三种方式共用同一条知识主线。

阅读 · 建议预留 5 分钟 · 无需 GPU

选择学习方式

方式学习活动需要什么
观看学习阅读讲解，操作 3D 模型，查看媒体示例并回答检查题。现代浏览器
固定模型实践（推荐）复制命令，在本机终端运行仿真，观察与记录结果。已准备好的 GPU 环境
训练练习在实践基础上自己训练、导出和评估。更多运行时间和磁盘空间

首次学习建议先使用固定模型完成课程主线，再回到第三章和第五章练习训练流程。即使没有 GPU，也可以按顺序完成阅读；交互模型和媒体示例都无需启动 Isaac。

预备知识

  • 能够在 Linux 中打开终端、切换目录和复制多行命令。
  • 能读懂简单的 Python 函数、数组和参数。无需先掌握 PPO。
  • 知道坐标、角度和速度的含义；课程会解释机器人坐标系。
关于训练结果

自行训练得到的检查点只是练习产物。后续章节仍默认使用 models/ 中的课程模型，不会自动选取“最近训练的模型”。如需改用自行训练的策略，必须明确指定检查点，并重新进行评估。

每次实验怎么做

  • 先阅读“预期结果”，明确需要观察的现象。
  • 在课程仓库根目录执行命令。每个输出目录只用于一次运行。
  • 保存运行命令、随机种子和结果，失败记录也要保留。
  • 回答本章检查题，再进入下一章。

正文标注的阅读与练习时长仅供安排学习进度，并不保证训练能在相同时间内完成。首次启动还可能需要下载资源、编译内核并创建渲染缓存。
