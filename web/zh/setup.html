SELF-PACED WORKSHOP

准备环境与获取代码

把课程页面、实验代码和固定模型放到同一个工作目录，然后检查运行环境。

操作实验 · Ubuntu 24.04 / DGX Spark

运行条件

这里以 Ubuntu 24.04、DGX Spark（aarch64）、Python 3.12、Isaac Sim 6 以及锁定版本的 Isaac Lab / Newton 作为参考运行环境，仿真采用 Newton 的原生执行器路径。其他 GPU 或软件版本或许也能运行，但这些测试结果不能直接套用。

运行实验需要 NVIDIA 驱动、支持 GPU 的图形桌面、Git、Docker，以及能够访问 NVIDIA 软件源的网络；仅浏览课程网页则无需安装这些组件。安装 Isaac Sim 前，请先阅读其软件许可。

下载课程与模型

在您希望存放课程的目录打开终端，运行下面的命令下载仓库并进入课程目录。

Terminal · Bash
mkdir -p "$HOME/microduck"
cd "$HOME/microduck"
git clone https://github.com/NV-DLI/Microduck-Workshop.git
cd Microduck-Workshop
python3 scripts/workshop.py verify-models

模型会随仓库一同下载，无需另行登录 Hugging Face。校验命令会逐一核对文件的 SHA-256；只有全部一致后才能继续。提供的固定权重应与自行生成的输出分开保存。

Workspace
Microduck-Workshop/
├── web/          # HTML course
├── lab/          # simulation and learning code
├── models/       # fixed course models
├── scripts/      # lab entry points
└── outputs/      # your runs (created when needed)

准备仿真环境

先确认系统工具可用。下面的命令将安装 Git、Python 虚拟环境支持和视频编码工具。Docker 需要预先按照 Ubuntu 安装说明 完成配置；运行 docker info 应能看到服务信息，且不能出现权限错误。

Terminal · Bash
sudo apt-get update
sudo apt-get install -y git python3-venv ffmpeg
docker info
export UV_HTTP_TIMEOUT=600
Terminal · Bash
python3 scripts/workshop.py setup
python3 scripts/workshop.py doctor

setup 会显示并执行锁定版本的安装步骤；如果已有版本匹配的 Isaac Lab，可以使用 --isaaclab /你的/IsaacLab目录 进行绑定。doctor 用于检查 Python、模型、GPU、桌面显示变量和导航依赖；所有失败项都应先处理完毕。

在桌面终端启动

需要图形界面的命令应在 GPU 机器的桌面终端中执行。课程网页只提供教材和命令，Isaac 窗口不会嵌入浏览器。首次打开场景时，请等待着色器和资源全部加载完成。

确认可以开始

在课程仓库根目录的终端中运行下面的命令，完成本节操作。若命令包含输出目录，请使用尚不存在的新目录，以保留此前的结果。

Terminal · Bash
python3 scripts/workshop.py inspect-model --model models/walk.onnx

预期结果：终端显示模型输入与输出的名称、形状，以及模型的 SHA-256 标识。如果系统未识别到 GPU，请先查阅故障排查；不要通过更换物理引擎或随意下载其他模型来绕过检查。
