SELF-PACED WORKSHOP

准备环境与获取代码

把课程页面、实验代码和固定模型放到同一个工作目录，然后检查运行环境。

操作实验 · Ubuntu 24.04 / DGX Spark

运行条件

本课程的参考运行环境是 Ubuntu 24.04、DGX Spark（aarch64）、Python 3.12、Isaac Sim 6.2 和锁定版本的 Isaac Lab / Newton。仿真使用 Newton 的原生执行器路径。其他 GPU 或版本可能可以运行，但不能直接沿用课程的测试结果。

需要 NVIDIA 驱动、支持 GPU 的图形桌面、Git、Docker 和可访问 NVIDIA 软件源的网络。观看网页不需要安装这些组件。安装 Isaac Sim 前，请阅读其软件许可。

下载课程与模型

Terminal · Bash
mkdir -p "$HOME/microduck"
cd "$HOME/microduck"
git clone https://github.com/NV-DLI/Microduck-Workshop.git
cd Microduck-Workshop
python3 scripts/workshop.py verify-models

模型随仓库下载，不需要单独登录 Hugging Face。校验命令逐个核对文件的 SHA-256；所有文件一致才继续。课程固定权重和你自己的输出分开保存。

Workspace
Microduck-Workshop/
├── web/          # HTML course
├── lab/          # simulation and learning code
├── models/       # fixed course models
├── scripts/      # lab entry points
└── outputs/      # your runs (created when needed)

准备仿真环境

先确认系统工具可用。下面安装 Git、Python 虚拟环境支持和录像编码工具。Docker 需先按其 Ubuntu 安装说明 准备好；docker info 应能显示服务信息，不应报权限错误。

Terminal · Bash
sudo apt-get update
sudo apt-get install -y git python3-venv ffmpeg
docker info
export UV_HTTP_TIMEOUT=600
Terminal · Bash
python3 scripts/workshop.py setup
python3 scripts/workshop.py doctor

setup 显示并执行锁定版本的安装步骤；如果已有符合版本的 Isaac Lab，可以用 --isaaclab /你的/IsaacLab目录 绑定。doctor 检查 Python、模型、GPU、桌面显示变量和导航依赖；显示的失败项必须先处理。

在桌面终端启动

需要图形界面的命令应在 GPU 机器的桌面终端执行。网页只提供教材与命令，不会把 Isaac 窗口嵌入浏览器。首次打开场景时，请等待着色器和资源加载完成。

确认可以开始

Terminal · Bash
python3 scripts/workshop.py inspect-model --model models/walk.onnx

预期结果：模型输入与输出的名称、形状和固定模型校验信息。看不到 GPU 时先阅读故障排查；不应通过更换物理引擎或随机下载一个模型来绕过检查。
