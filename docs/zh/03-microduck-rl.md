{#task}
## 把行走写成强化学习任务

2.1 和 2.2 节运行的是官方训练好的行走策略。它要学会的是：接收前进、横移和转向的速度指令，协调 14 个关节，在不跌倒的前提下跟上指令。把 3.1 节的概念逐一对应到这个任务：

| 强化学习概念 | Microduck 行走任务中的对应 |
|---|---|
| 观测 | 61 维：机身角速度、重力方向、14 个关节的角度与角速度、上一步动作，以及速度、头部和机身姿态指令（顺序见 <a href="02-anatomy.html#policy-interface">2.2 节</a>） |
| 目标指令 | 前进 −0.4～0.4 m/s、横移 −0.3～0.3 m/s、转向 −1.0～1.0 rad/s，每隔 3–8 秒重新抽取；练习原地站立的环境从 2% 起，随训练逐级增至 25% |
| 动作 | 14 维：各关节目标角度相对默认站姿的偏移，每 20 ms（50 Hz）输出一次 |
| 奖励 | 速度跟踪、站直、站姿、抬脚与落脚、动作平滑等多项加权求和 |
| 回合结束 | 机身倾斜超过 70° 判为跌倒；否则最长 20 秒（1000 个控制步） |

训练时，Newton 在 GPU 上同时推进上千个环境，Isaac Lab 为每个环境计算观测、奖励和终止，RSL-RL 的 PPO 用这些数据更新网络。PPO 不需要预先下载数据集：训练数据就是这些环境实时产生的交互。

{#actor-critic}
## Actor 与 Critic 的分工

```{learning-flow}
label: 部署时运行的 Actor
nodes:
- [61 维观测, 机器人能测到的状态与指令]
- [Actor, 512-256-128 全连接网络]
- [14 维动作, 关节目标偏移]
details:
- 观测只包含真机上也能获得的量：IMU、关节编码器、上一步动作和指令。训练时还给它们加入噪声，模拟传感器误差。
- Actor 有三层隐藏层（512、256、128）。训练时它输出动作分布并从中采样，以便探索；导出部署时只保留确定的输出。
- 14 个数加到默认站姿上，得到各关节的目标角度，再交给舵机模型和物理仿真。
caption: 这是部署时运行的部分。Critic 不在这条链路上，它只在训练时与 Actor 并行工作。
```

Actor 和 Critic 读取各自的观测，并行工作：

| | Actor（策略） | Critic（价值函数） |
|---|---|---|
| 输入 | 61 维观测，带噪声 | Actor 的观测，加上机身线速度、脚的高度、腾空时间、接触状态与接触力，不加噪声 |
| 输出 | 14 维关节动作 | 一个数：从当前状态出发的预期回报 |
| 训练中的作用 | 与环境交互、产生动作；按优势更新 | 给出预期回报，用来计算每个动作的优势；自身按实际回报更新 |
| 部署 | 导出为 ONNX，在机器人上运行 | 不需要 |

Critic 可以使用真机上拿不到的仿真信息，因为它不需要部署；它估计得越准，优势就越可靠，Actor 学得也越稳。Actor 则必须只依赖真机能获得的观测，否则导出后无法运行。

{#reward-design}
## 奖励在评价什么

只奖励速度接近指令，机器人可能学到不稳定的移动方式；只奖励站直，又可能学会原地不动。所以奖励由多项组成，每项回答一个问题：

| 奖励项 | 权重 | 它在问什么 |
|---|---|---|
| 线速度跟踪 | 2.0 | 水平速度是否接近指令，有没有上下跳动 |
| 角速度跟踪 | 2.0 | 机身 z 轴角速度是否跟上转向指令，同时横滚、俯仰角速度是否足够小 |
| 站直 | 2.0 | 机身是否保持竖直 |
| 站姿 | 1.0 | 关节是否离默认站姿太远 |
| 腾空时间 | 3.0 | 是否迈出完整的步子，而不是拖着脚走 |
| 抬脚高度与离地 | −1.1、−2.0 | 摆动脚是否抬到合适高度 |
| 足底滑动 | −0.1 | 着地的脚是否打滑 |
| 动作变化 | −0.1 起，随训练加大 | 相邻两步的动作是否突变 |

权重取自完整训练保存的 `env.yaml`。跟踪类奖励在误差为 0 时最大、误差越大越小；带负权重的项是惩罚。多项相加后，机器人只有“既跟上指令，又走得稳、走得顺”才能拿到高分。3.3 节给出线速度跟踪项的实际代码，3.4 和 3.5 节继续讨论怎样设计奖励。

::::{quiz}
Critic 的输入里有机身线速度和足部接触力，Actor 没有。为什么不把这些也给 Actor？

:::{answer}
Actor 要部署到机器人上，只能使用真机能可靠测到的量；机身线速度和接触力在真机上很难准确测量。Critic 只在训练时使用，可以读取仿真中的这些信息，让回报估计更准。
:::
::::
