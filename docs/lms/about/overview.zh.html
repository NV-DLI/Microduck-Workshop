本课程带你使用 NVIDIA Isaac Sim 与 Isaac Lab，在仿真中让开源双足机器人 Microduck 学会技能。你将用 PPO 和奖励设计训练行走与上下坡，再了解手工设计的射门流程。最后，使用示范数据对 NVIDIA Isaac GR00T 进行后训练，在仿真中评测步行射门表现。

Isaac Sim, Isaac Lab, GR00T

  • 具备基础 Python 经验，熟悉 Ubuntu 命令行。
  • 运行实验需要 Ubuntu 与 NVIDIA GPU。

完成本课程后，你将能够：

  • 在 Isaac Sim 中运行 Microduck 仿真，查看策略的观测、动作和控制周期。
  • 解释 PPO 的基本原理，用 Isaac Lab 与 Newton 运行行走策略的训练与验证。
  • 设计奖励和域随机化，结合 TensorBoard 曲线与独立评测结果判断训练效果。
  • 说明板载策略怎样串联 YOLO 识别、ToF 测距、Nav2 规划与动作技能，并分析射门结果。
  • 使用课程提供的示范数据体验 GR00T 动作头后训练，并在仿真中评测提供的检查点。
  • 解释模型走向新环境时面临的泛化挑战，以及环境随机化可以怎样帮助模型适应这些变化。

下表按课程的六个部分列出主要内容，你可以按自己的节奏依次学习。

1. 概览
  • 了解课程路线与学习目标
  • 构建并进入课程容器
  • 确认 Isaac Sim 与 GPU 可用
2. 认识 Microduck
  • 在 Isaac Sim 中用键盘指挥 Microduck 行走与踢球
  • 认识机械结构、关节、执行器与传感器
  • 理解策略的控制周期
3. 用强化学习训练技能
  • 理解强化学习与 PPO 的基本原理
  • 用 Isaac Lab 与 Newton 训练并测试行走策略，理解域随机化的作用
  • 设计奖励，让 Microduck 走稳上下坡
  • 阅读社区技能的奖励代码：单脚站立、篮球平衡与倒滑
4. 板载策略完成射门
  • 用 RGB、ToF 与小型 YOLO 检测器识别足球、球门并估计距离
  • 串联 Nav2 规划与动作技能，循环运行射门并分析成功与失败
5. 训练 GR00T 完成任务
  • 理解视觉-语言-动作模型与 GR00T
  • 了解步行射门的 8 维高层请求接口与示范数据
  • 体验动作头后训练，并用课程提供的检查点验证步行射门
  • 讨论环境随机化怎样帮助模型走向更多环境
6. 参考与帮助
  • 查阅课程模型与数据
  • 排查常见问题
  • 继续学习的参考资料
