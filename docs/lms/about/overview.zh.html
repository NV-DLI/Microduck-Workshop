本课程带你使用 NVIDIA Isaac Sim 与 Isaac Lab，在仿真中让开源双足机器人 Microduck 学会技能。你将用 PPO 和奖励设计训练行走与上下坡，再了解手工设计的射门流程。最后，使用示范数据对 NVIDIA Isaac GR00T 进行后训练，在仿真中评测步行射门表现。

免费课程 · 预计学习时间约 6 小时（不含完整训练的等待时间；训练可以随时停止，验证默认使用课程提供的检查点）。

  • NVIDIA Isaac Sim：场景、机器人与 RGB/ToF 传感器仿真。
  • NVIDIA Isaac Lab 与 Newton：并行强化学习训练、物理仿真与策略评测。
  • NVIDIA Isaac GR00T 与 LeRobot：示范数据、视觉-语言-动作模型与动作头后训练。
  • PPO、RSL-RL、PyTorch 与 TensorBoard：策略优化、训练实现与曲线分析。
  • ROS 2 与 Nav2：板载策略的路径规划。
  • Python、Docker 与 NVIDIA Container Toolkit：运行课程代码与 GPU 容器。
  • 具备基础 Python 经验，熟悉 Ubuntu 命令行。
  • 运行实验需要 Ubuntu 与 NVIDIA GPU，具体设备要求见课程“1.2 准备环境与获取代码”。

完成本课程后，你将能够：

  • 在 Isaac Sim 中运行 Microduck 仿真，查看策略的观测、动作和控制周期。
  • 解释 PPO 的基本原理，用 Isaac Lab 与 Newton 运行行走策略的训练与验证。
  • 设计奖励和域随机化，结合 TensorBoard 曲线与独立评测结果判断训练效果。
  • 说明板载策略怎样用 RGB 检测、ToF 测距和手工设计的阶段完成射门。
  • 使用课程提供的示范数据体验 GR00T 动作头后训练，并在仿真中评测提供的检查点。
  • 解释模型走向新环境时面临的泛化挑战，以及环境随机化可以怎样帮助模型适应这些变化。
部分 主要内容
1 概览 课程路线；构建并进入课程容器，确认 Isaac Sim 与 GPU 可用
2 认识 Microduck 在 Isaac Sim 中用键盘指挥行走与踢球；拆解关节、执行器、传感器与控制周期
3 强化学习 强化学习与 PPO；用 Isaac Lab 与 Newton 训练并测试行走策略；域随机化与上下坡奖励设计；社区技能的奖励代码
4 板载策略 RGB 检测与 ToF 测距；手工设计的射门阶段
5 GR00T 视觉-语言-动作模型与 GR00T；8 维高层请求接口与示范数据；动作头后训练与检查点验证；走向更多环境
6 参考与帮助 模型与数据；故障排查；继续学习与参考资料
