本课程带您使用 NVIDIA Isaac Sim 与 Isaac Lab，在仿真环境中训练和验证开源双足机器人 Microduck，为后续 sim2real（从仿真迁移到真实环境）打下基础。自主射门是课程中的综合案例之一。您将用 PPO、域随机化和奖励设计训练行走与上下坡，再运行人工设计的板载策略完成步行射门。最后，了解 NVIDIA Isaac GR00T 怎样从示范中学会步行射门。

Isaac Sim, Isaac Lab, GR00T

  • 具备基础 Python 经验，熟悉 Ubuntu 命令行。
  • 运行实验需自备配有 NVIDIA DGX 系统 GPU 或 RTX GPU 的 Ubuntu 计算机，并满足 Isaac Sim 的显存、RTX 渲染与驱动要求。支持 Intel / AMD x86_64 与 DGX Spark ARM CPU；全部实验仅在 DGX Spark 上测试过，不要求必须使用 Spark。

完成本课程后，您将能够：

  • 在 Isaac Sim 中运行 Microduck 仿真，查看策略的观测、动作和控制周期。
  • 解释 PPO 的基本原理，用 Isaac Lab 与 Newton 运行行走策略的训练与验证。
  • 设计奖励和域随机化，结合 TensorBoard 曲线与独立评测结果判断训练效果。
  • 说明板载策略怎样串联 YOLO 识别、ToF 测距、直线接近与动作技能，并分析射门结果。
  • 说明 GR00T 怎样用 8 维高层请求与已训练的底层技能分工完成射门，以及示范数据、动作头训练和闭环验证的思路。
  • 解释模型走向新环境时面临的泛化挑战，以及环境随机化可以怎样帮助模型适应这些变化。

下表按课程的六个部分列出主要内容，您可以按自己的节奏依次学习。

1. 概览
  • 了解课程路线与学习目标
  • 构建并进入课程容器
  • 确认 Isaac Sim 与 GPU 可用
2. 认识 Microduck
  • 在 Isaac Sim 中用键盘指挥 Microduck 行走与踢球
  • 认识机械结构、关节、执行器与传感器
  • 理解策略的控制周期
3. 用强化学习训练技能
  • 理解强化学习与 PPO 的基本原理
  • 把观测、动作、奖励与 Actor/Critic 对应到 Microduck 行走
  • 用 Isaac Lab 与 Newton 训练并测试行走策略，理解域随机化的作用
  • 延伸：设计奖励，让 Microduck 走稳上下坡
  • （拓展）社区技能的奖励设计：单脚站立与篮球平衡
4. 板载策略完成射门
  • 用 RGB、ToF 与小型 YOLO 检测器识别足球、球门并估计距离
  • 用直线接近和反馈调整串联动作技能，反复运行射门并分析成功与失败
5. （拓展）使用 GR00T 自主完成射门
  • 理解视觉-语言-动作模型（VLA）与 GR00T
  • 了解 GR00T 怎样用 8 维高层请求与已训练技能完成步行射门
  • 理解背后的示范数据、动作头训练与闭环验证
  • 讨论环境随机化怎样帮助模型走向更多环境
6. 参考与帮助
  • 借助自己的智能体设计和实现机器人任务
  • 排查常见问题
  • 继续学习的参考资料
